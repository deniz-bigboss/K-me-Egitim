Yönetici Girişi

Haber eklemek için GitHub erişim anahtarınızı girin. Anahtar yalnızca bu tarayıcıda saklanır, hiçbir yere gönderilmez.

Anahtarı nasıl alırım?
  1. GitHub → sağ üst profil → Settings
  2. En altta Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Repository access: Only select repositories → K-me-Egitim
  5. Permissions → Repository permissions → Contents: Read and write
  6. Oluştur, çıkan anahtarı kopyalayıp buraya yapıştır

Anahtarı kimseyle paylaşmayın. Kaybolursa GitHub'dan iptal edip yenisini üretebilirsiniz.
