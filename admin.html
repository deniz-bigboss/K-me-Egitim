Yönetici Girişi

Bu panelden haber ekleyebilir ve sınıfların ders programlarını yükleyebilirsiniz. Giriş için bir kez erişim anahtarı oluşturmanız gerekiyor.

İlk kez mi giriyorsunuz?

Anahtarı bir kez oluşturmanız yeterli; sonra hep aynısını kullanırsınız. Aşağıdaki butona basın ve açılan GitHub sayfasında şu 4 ayarı yapın:

  1. Token name: istediğiniz bir isim (örn. Kume Panel)
  2. Expiration: No expiration seçin (yoksa süresi dolunca yenilemeniz gerekir)
  3. Repository access: Only select repositories → listeden K-me-Egitim seçin
  4. Permissions → Repository permissions → Contents satırını Read and write yapın

Sayfanın en altındaki Generate token butonuna basın. Ekranda çıkan uzun yazıyı kopyalayıp yukarıdaki kutuya yapıştırın. Bu yazı yalnızca bir kez gösterilir, kaybederseniz yenisini oluşturursunuz.

Anahtar Oluştur (GitHub)

Anahtarınız yalnızca kendi tarayıcınızda saklanır, kimseyle paylaşılmaz. Anahtarı kaybederseniz veya birine verirseniz GitHub'dan iptal edip yenisini üretebilirsiniz.
